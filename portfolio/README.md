# nedapi studio — портфолио

Одностраничный сайт-портфолио: работы, процесс работы с клиентом, цены, контакты.

- `index.html` — вся страница (разметка + стили + скрипт в одном файле)
- `assets/` — скриншоты кейсов, фотографии, шрифты (self-hosted woff2)
- `PRODUCT.md` — что это за продукт и для кого
- `DESIGN.md` — визуальная система: токены, типографика, приёмы

## Публикация

Репозиторий рассчитан на GitHub Pages: Settings → Pages → Deploy from a branch → выбрать ветку и папку `/ (root)`.
Файл `.nojekyll` отключает обработку Jekyll, чтобы папки с ассетами отдавались как есть.

## Что менять при правках

| Что | Где искать в `index.html` |
|---|---|
| Telegram | `https://t.me/nedapi` |
| Телефон | `tel:+79856040486` и текст `+7 985 604‑04‑86` |
| Цена | блок `price-num` и строки в `hero-note` / футере |
| Проценты предоплаты | секция `#process` |
| Новый кейс | скопировать блок `<article class="case">` внутри `#works` |
| Ссылки на сайты | `bonifirmaarm-design.github.io/auto-website/` и `.../flowers/` |

Все изображения — `webp`, шрифты подключены локально из `assets/fonts`, внешних зависимостей у страницы нет.
