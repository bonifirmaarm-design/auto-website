# CLAUDE.md — рабочие правила проекта

Этот репозиторий укомплектован набором **дизайн- и фронтенд-навыков** (skills) в
`.claude/skills/`. Claude Code автоматически подгружает их описания в каждой
сессии и вызывает нужный навык, когда задача ему соответствует.

## Главное правило

**Каждый раз, когда пишешь или правишь UI / фронтенд / визуальную часть — сначала
подключай подходящий навык из `.claude/skills/`, а потом пиши код.** Не выдавай
«шаблонный» интерфейс по умолчанию: сверься с навыком по типографике, цвету,
сетке, отступам, доступности и микровзаимодействиям.

Практический порядок работы над любой визуальной задачей:

1. **Определи тип задачи** и возьми профильный навык (см. индекс ниже).
2. Для новой страницы/лендинга/портфолио → `frontend-design`, `taste-skill`,
   `impeccable`, `hallmark` или `frontend-design-pro`.
3. Для продуктового UI (дашборды, админки, SaaS, формы) → `interface-design`,
   `ui-ux-pro-max`, `ui-styling`.
4. Перед сдачей — прогони ревью: `web-design-guidelines`, `ux-heuristics`,
   `accessibility-audit`, `ui-refactor`.
5. React/Next.js код → соблюдай `react-best-practices` и `composition-patterns`.

Навык вызывается инструментом Skill (например `Skill(skill="impeccable")`), либо
Claude Code подхватывает его сам по описанию. Многие навыки user-invocable —
их можно звать как `/<имя-навыка>`.

## Индекс навыков (`.claude/skills/`)

### Визуальный дизайн и «вкус» (anti-slop)
- **frontend-design** — интенциональный визуальный дизайн нового/существующего UI.
- **frontend-design-pro** — production-ready интерфейсы + подбор реальных фото.
- **impeccable** — большой навык: дизайн, редизайн, критика, аудит, полировка,
  анимация, типографика, токены (user-invocable, много под-режимов).
- **hallmark** — анти-AI-slop: greenfield-страницы, аудиты, извлечение дизайна из URL/скринов.
- **taste-skill** — анти-slop для лендингов, портфолио и редизайнов.
- **redesign-skill** — апгрейд существующих сайтов/приложений до премиум-качества.
- **image-to-code-skill** — превращение дизайн-изображения в код.

### Готовые арт-направления (стили)
- **minimalist-skill** — чистый редакторский минимализм.
- **brutalist-skill** — брутализм / терминальная эстетика.
- **soft-skill** — «агентский» premium-look: шрифты, тени, карточки, анимации.
- **brandkit** — брендбуки, логосистемы, identity-борды.
- **brand** — brand voice, визуальная айдентика, messaging.
- **banner-design** — баннеры для соцсетей, рекламы, hero-блоков, печати.
- **slides** — HTML-презентации с Chart.js и дизайн-токенами.

### Продуктовый UI / фронтенд-инжиниринг
- **interface-design** — дашборды, админки, SaaS, настройки, дата-интерфейсы.
- **ui-ux-pro-max** — большая база: стили, палитры, шрифт-пары, UX-гайдлайны, стеки.
- **ui-styling** — shadcn/ui + Radix + Tailwind, доступные компоненты.
- **react-best-practices** — производительность React/Next.js (гайд Vercel).
- **composition-patterns** — паттерны композиции React-компонентов.
- **react-view-transitions** — плавные переходы через React View Transition API.
- **img2threejs** — референс-изображение → анимируемая процедурная Three.js-модель.
- **scroll-craft** — скролл-анимации и повествование через прокрутку.

### Дизайн-система и токены
- **design-system** — трёхслойные токены (primitive→semantic→component), CSS-переменные.
- **design-token** — определение и организация токенов (цвет/отступы/тип/тени).
- **color-system** — тональные шкалы, семантические роли, контраст.
- **typography** / **typography-scale** — типографика и модульная шкала.
- **spacing-system** — шкала отступов от базовой единицы.
- **layout-grid** — адаптивная сетка (колонки, гаттеры, брейкпоинты).
- **responsive-design** — адаптивность под экраны и способы ввода.
- **dark-mode-design** — перенос палитры в тёмную тему.
- **motion-system** — токены движения (длительности, easing, reduced-motion).

### Взаимодействие и микроанимации
- **form-design** — формы: порядок полей, группировка, валидация.
- **animation-principles** — принципы анимации для конкретного движения UI.
- **micro-interaction-spec** — полная спецификация одного микровзаимодействия.
- **loading-states** — спиннеры, скелетоны, оптимистичные апдейты.
- **navigation-patterns** — выбор паттерна навигации под структуру продукта.
- **visual-hierarchy** — визуальная иерархия (размер, вес, цвет, пространство).

### Ревью, аудит, методология
- **web-design-guidelines** — ревью UI-кода на соответствие Web Interface Guidelines.
- **ux-heuristics** — эвристический анализ юзабилити (Nielsen, Krug).
- **accessibility-audit** — аудит по WCAG с приоритизацией и фиксами.
- **ui-refactor** — тактический гайд по починке макетов, цветов, шрифтов.
- **design-audit** — аудит дизайна.
- **innovative-ux-designer** — независимый визуальный язык → production-графика.
- **design-sprint** — 5-дневный дизайн-спринт для валидации идей.

## Источники

Навыки собраны из открытых репозиториев (см. `.claude/skills/SOURCES.md`).
Лицензии и авторство сохранены внутри каждого навыка.
